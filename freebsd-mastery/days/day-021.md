## Bloc 1 — Récupération à blanc (15 min)

Sans regarder aucune note.

### 1.1 Cycle de vie complet d'un processus
Dessine sur papier :
- Les états : NEW → RUNNABLE → RUNNING → SLEEPING → ZOMBIE → DEAD.
- Les événements qui déclenchent chaque transition.
- Les syscalls impliqués (fork, exec, exit, wait, sleep, signal…).

### 1.2 fork() — chaîne d'appels
Retrace de mémoire la chaîne dans kern_fork.c. Note les 5 ressources copiées dans l'ordre.

### 1.3 exec() — avant/après
Dessine un tableau : pour chaque ressource (vmspace, fd, signaux, threads, PID), ce qui est préservé et ce qui est remplacé lors d'un exec().

### 1.4 Signaux
Dessine le chemin d'un SIGINT depuis Ctrl-C jusqu'au handler (ou action par défaut) du processus.

### 1.5 ULE
Explique en 5 lignes le fonctionnement d'ULE : run queues, niveaux de priorité, interactivité.
