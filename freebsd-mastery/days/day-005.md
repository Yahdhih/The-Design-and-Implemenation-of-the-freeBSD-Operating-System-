## 💻 Code — 40 min

### Objectif

Écrire un programme C minimal, le compiler avec `code/common/Makefile`, et l'exécuter sous `truss` (FreeBSD) ou `strace` (Linux) pour **voir** les appels système en direct.

### Partie A — Mise en place de code/common/ (10 min)

```sh
cd freebsd-mastery/code/common
# Vérifier que le Makefile fonctionne :
make clean
# Créer hello_trace.c :
```

Crée `code/common/hello_trace.c` avec ce contenu :

```c
#include <stdio.h>
#include <unistd.h>
#include <fcntl.h>

int main(void) {
    /* Écrit sur stdout */
    write(STDOUT_FILENO, "hello\n", 6);

    /* Ouvre, lit, ferme un fichier */
    int fd = open("/etc/hostname", O_RDONLY);
    if (fd >= 0) {
        char buf[64] = {0};
        read(fd, buf, sizeof(buf) - 1);
        close(fd);
        write(STDOUT_FILENO, buf, __builtin_strlen(buf));
    }
    return 0;
}
```

```sh
make hello_trace
./hello_trace
# Attendu : "hello" suivi du hostname
```

### Partie B — Traçage sous truss/strace (30 min)

**Sur FreeBSD :**
```sh
truss ./hello_trace 2>&1 | head -40
```

**Sur Linux :**
```sh
strace ./hello_trace 2>&1 | head -40
```

**Sur macOS :**
```sh
dtruss ./hello_trace 2>&1 | head -40
# (peut nécessiter sudo ou désactivation SIP)
```

### Questions à répondre depuis la trace (note les réponses dans ton résumé)

1. Quels appels système précèdent le premier `write("hello\n")` que tu as écrit ? Pourquoi le runtime C en ajoute-t-il ?
2. Quel est le numéro de fd retourné par `open("/etc/hostname")` ?
3. Combien d'octets `read()` retourne-t-il ? Est-ce exactement `sizeof(buf)-1` ?
4. Y a-t-il des appels système que tu n'as pas écrits toi-même (ex. : `mmap`, `mprotect`, `execve`) ? À quoi servent-ils ?

### Partie C — Expérience bonus (si temps)

Trace le binaire `/bin/ls` :
```sh
truss /bin/ls /tmp 2>&1 | grep -E "open|read|write|close" | head -20
```
Identifie le pattern d'ouverture du répertoire et des fichiers.
