### Objectif

Améliorer `minishell.c` : SIGINT correctement géré, SIGCHLD, job en arrière-plan avec `&`.

### Partie A — SIGINT ne tue pas le shell (15 min)

Un shell doit ignorer SIGINT pour lui-même et laisser le fils le recevoir normalement :

```c
/* Dans main(), AVANT la boucle principale : */
struct sigaction sa_ignore = { .sa_handler = SIG_IGN };
sigaction(SIGINT, &sa_ignore, NULL);
sigaction(SIGQUIT, &sa_ignore, NULL);

/* Dans le fils (après fork(), avant execvp()) : */
struct sigaction sa_default = { .sa_handler = SIG_DFL };
sigaction(SIGINT, &sa_default, NULL);
sigaction(SIGQUIT, &sa_default, NULL);
```

Test :
```sh
./minishell
$ sleep 10
# Appuie Ctrl-C → sleep doit s'arrêter, le shell doit afficher "$" à nouveau
# Le shell ne doit PAS mourir
```

### Partie B — Commandes en arrière-plan avec `&` (15 min)

Détecte `&` à la fin des arguments :

```c
/* Avant fork(), vérifie si le dernier arg est "&" */
int background = 0;
int argc_real = /* nombre d'args calculé */;
if (argc_real > 0 && strcmp(argv[argc_real - 1], "&") == 0) {
    background = 1;
    argv[argc_real - 1] = NULL;
}

/* Après fork(), dans le père : */
if (background) {
    printf("[job %d]\n", pid);
    /* Ne pas appeler waitpid() — le job tourne en arrière-plan */
} else {
    /* waitpid normal */
}
```

Test :
```sh
./minishell
$ sleep 3 &
[job 1234]
$ ls          # s'exécute pendant que sleep tourne
$ # après 3 secondes, le shell doit récupérer le fils (via SIGCHLD ou waitpid(-1))
```

### Partie C — SIGCHLD pour récolter les jobs terminés (10 min)

```c
/* Handler SIGCHLD : récolte tous les fils terminés sans bloquer */
static void sigchld_handler(int sig) {
    (void)sig;
    int status;
    pid_t pid;
    while ((pid = waitpid(-1, &status, WNOHANG)) > 0)
        printf("\n[job %d terminé]\n", pid);
}

/* Dans main() : */
struct sigaction sa_chld = { .sa_handler = sigchld_handler, .sa_flags = SA_RESTART };
sigaction(SIGCHLD, &sa_chld, NULL);
```

**Critère** : `sleep 2 &` suivi de `ls` fonctionne ; le message « [job NNN terminé] » apparaît après 2 secondes.
