### Partie B — Tracer un socket TCP minimal (20 min)

Crée `code/common/tcp_probe.c` : un client TCP ultra-minimal.

```c
#include <stdio.h>
#include <string.h>
#include <unistd.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>

int main(void) {
    /* Chaque appel système sera visible dans truss */
    int fd = socket(AF_INET, SOCK_STREAM, 0);
    if (fd < 0) { perror("socket"); return 1; }

    struct sockaddr_in addr = {0};
    addr.sin_family = AF_INET;
    addr.sin_port   = htons(9999);
    inet_aton("127.0.0.1", &addr.sin_addr);

    /* connect échouera (rien n'écoute) — c'est voulu */
    int r = connect(fd, (struct sockaddr *)&addr, sizeof(addr));
    printf("connect: %d\n", r);
    close(fd);
    return 0;
}
```

```sh
make tcp_probe
truss ./tcp_probe 2>&1
```

**Questions de trace** :
1. Quel est le numéro du fd socket créé ? Pourquoi ce numéro (et pas 0 ou 1) ?
2. Quels arguments passe le noyau à `socket()` en interne ? Compare avec les constantes `AF_INET`, `SOCK_STREAM` dans `<sys/socket.h>`.
