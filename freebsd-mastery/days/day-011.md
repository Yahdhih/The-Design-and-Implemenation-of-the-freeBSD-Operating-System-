## 💻 Code — 40 min

### Objectif

Implémenter `code/01-processes/fork_exec.c` : un programme qui crée un fils via `fork()`, fait exécuter `/bin/ls -l` via `exec()`, et attend le résultat via `wait()`.

### Jalon 1 — fork/exec/wait (25 min)

Crée `code/01-processes/fork_exec.c` :

```c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/wait.h>

int main(void) {
    pid_t pid = fork();

    if (pid < 0) {
        perror("fork");
        return 1;
    }

    if (pid == 0) {
        /* Fils : exécute ls -l */
        char *args[] = { "/bin/ls", "-l", ".", NULL };
        execv("/bin/ls", args);
        perror("execv"); /* si on arrive ici, execv a échoué */
        exit(1);
    }

    /* Père : attend le fils */
    int status;
    pid_t waited = waitpid(pid, &status, 0);

    if (WIFEXITED(status))
        printf("fils (PID %d) terminé avec code %d\n", waited, WEXITSTATUS(status));
    else if (WIFSIGNALED(status))
        printf("fils (PID %d) tué par signal %d\n", waited, WTERMSIG(status));

    return 0;
}
```
